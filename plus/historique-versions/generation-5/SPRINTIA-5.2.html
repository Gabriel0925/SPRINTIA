SPRINTIA 5.2

Date

05 Août 2026

Taille

5,16 Mo

Résumé

SPRINTIA 5.2 introduit une toute nouvelle fonctionnalité bien pratique nommée : "Entraînement du jour". C'est parfois compliqué de trouver un entraînement à faire, on peut manquer d'idées ou de temps pour en créer un. L'outil "Entraînement du jour" a été conçu pour résoudre ce problème, il vous permet de générer un entraînement en fonction de l'intensité et de la durée que vous souhaitez. Une fois les entraînements générés, vous pouvez directement envoyer l'entraînement sur votre compte COROS.

Patch note

Nouvelles fonctionnalités

  • Un tout nouvel outil nommé : "Entraînement du jour" est disponible, cet outil est disponible pour 3 sports : Course, Vélo, Natation. Le but de l'outil "Entraînement du jour" est de générer un entraînement rapidement en fonction de l'intensité et de la durée que vous souhaitez, puis vous pouvez envoyer directement cet entraînement sur votre compte COROS grâce aux partages d'entraînements via lien de COROS.
  • Dans la page de discussion avec le coach vous avez désormais accès à une page de paramètres (nommée : "Paramètres discussion"). Cette page vous permet de garder le contrôle sur vos données partagées dans le prompt que SPRINTIA génère, vous pouvez désactiver le partage des données de votre profil (sexe, âge, taille, poids, FC repos).
  • Une toute nouvelle section nommée : "Dompter SPRINTIA" fait son apparition dans l'onglet "Plus". Cette nouvelle page permet de mieux comprendre SPRINTIA et d'avoir de courts tutos vidéo sur certaines fonctionnalités de SPRINTIA.
  • Lors d'un appui long sur l'icône de SPRINTIA un nouveau raccourci nommé "Entraînement du jour" remplace le raccourci de la charge d'entraînement ce qui vous permet d'aller très rapidement vers le générateur d'entraînement.
  • La fonctionnalité "Télécharge vos données" devient "Exporter vos données", elle regroupe le téléchargement classique du fichier contenant vos données mais une fonctionnalité a été ajouté pour éviter de manipuler manuellement les fichiers JSON pour passer d'un fichier à un autre. Vous pouvez partager le fichier directement via AirDrop, Quick Share, et les applications compatibles

Améliorations

  • Désormais l'import de votre historique d'entraînement depuis Garmin (en CSV) prend en compte plus de 25 nouveaux sports : Trail, Course sur piste, Course à pied sur tapis roulant, Course virtuelle, Ultrafond, VTT électrique, Vélo électrique, VTT enduro, Gravel bike, Vélo d'intérieur, VTT, Cyclisme sur route, Cyclisme sur piste, Cyclisme virtuel, BMX, Cyclo-cross, Tennis, Tennis de table, Rugby, HIIT, Cardio, Natation en eau libre, Snowboard backcountry, Snowboard en station, Ski de fond classique, Ski de fond skating, Escalade en salle et Corde à sauter.
  • SPRINTIA sait extraire plus de données du fichier CSV pour importer votre historique d'entraînement Garmin comme par exemple le dénivelé.
  • Un service worker a été ajouté pour pouvoir améliorer les fonctionnalités de la PWA.
  • Nouveau splash screen : la couleur de fond au lancement de l'application n'est plus du noir mais le bleu officiel de SPRINTIA ce qui améliore la cohérence.
  • Nouvelle icône ronde pour l'icône dans l'onglet de votre navigateur, ce qui est bien plus beau !
  • La fonctionnalité d'échange d'entraînement (qui est sortit avec SPRINTIA 5.1) passe à la vitesse supérieure, désormais vous n'avez plus besoin de télécharger le fichier puis ensuite de l'envoyer à votre ami, vous pouvez directement cliquer sur "Partager" pour l'envoyer directement à votre ami via AirDrop, Quick Share, et les applications compatibles avec le partage de fichiers.
  • Ajout d'une confirmation avant d'envoyer votre mail pour améliorer SPRINTIA, cela permet d'éviter les envois accidentels.

Correction des bugs et optimisations

  • Grosse optimisation du code d'import d'historique d'entraînement depuis un fichier CSV Garmin. Le code est désormais plus rapide, plus robuste, plus fiable mais surtout bien plus propre, les enchaînements de if/else ont disparu au profit de dictionnaires,... De plus, si SPRINTIA n'arrive pas à importer un entraînement lors de l'import de votre historique d'entraînement il ne plantera pas, il ignorera juste cet entraînement mais il importera le reste.
  • Correction d'un bug d'interface sur la carte de configuration de SPRINTIA sur la page d'accueil.
  • Le parcours utilisateur après l'import de données a été optimisé : lorsque vous importez un entraînement (TCX, GPX ou SPRINTIA), désormais l'application vous emmène directement dans la page de détail de l'entraînement ce qui vous permet de visualiser les données de votre entraînement directement. En revanche, lorsque vous importez un historique d'entraînement, SPRINTIA vous redirige vers la page d'entraînement. Enfin lorsque vous restaurez vos données, SPRINTIA vous redirige vers la page d'entraînement pour visualiser les statistiques de ce compte.
  • Lorsque vous enregistrez un entraînement, SPRINTIA vous redirige directement dans la page de détail d'entraînement.
  • Correction d'un bug majeur du calcul du dénivelé lors de l'import d'un fichier TCX/GPX. Désormais le calcul du dénivelé est bien plus précis et fiable car il prend en compte une tolérance ce qui efface les bruits/imprécisions GPS.
  • La tab-bar a désormais été adaptée à 100% pour la souris grâce à l'ajout d'un pointer de curseur.
  • Un bug majeur de la PWA a enfin été corrigé, ce bug est présent depuis les débuts de SPRINTIA sur le web (depuis février) ! Auparavant, lorsque l'utilisateur avait téléchargé SPRINTIA en tant qu'application, l'icône de l'application était figée. Même lorsque j'ai changé l'icône de SPRINTIA, si vous aviez déjà installé SPRINTIA sur votre appareil, l'icône de l'application ne changeait pas. Désormais, l'icône de l'application se met à jour grâce à un service worker !
  • Correction d'une incohérence pour les "select" dans les formulaires.
  • L'icône d'entraînement dans la tab-bar n'avait pas la bonne épaisseur ce qui n'était pas cohérent avec le reste des icônes.
  • Ajout d'un meilleur feedback lors du maintien appuyé sur le composant de votre IA favorite.
  • Sur la page d'entraînement, dans votre historique d'entraînement, le texte : "Charge d'entraînement" était coupé : "Charge d'entraî." ce qui n'était pas très précis.
  • Correction d'un bug du logo dynamique qui affichait parfois un message vide.
  • Correction d'un bug mineur mais c'était un détail qui me saoulait, il est désormais corrigé : parfois lors de la consultation du détail d'un entraînement les données "Transpiration estimée" et "Réhydratation conseillée" s'affichaient avant le dénivelé ou autre ce qui n'était pas normal.
  • L'interface de la page d'entraînement au premier démarrage de l'application a été améliorée sur ordinateur et sur tablette.
  • J'ai réécrit la page "à propos" pour être plus précis, d'ajouter le lien vers le dépôt GitHub ainsi que vers la chaîne YouTube où je réalise des tutos pour vous aider à prendre en main SPRINTIA.
  • Correction d'un lien qui renvoyait une erreur 404 dans la page de confidentialité.
  • La mise en page de la page de licence a été totalement refaite pour être bien plus lisible.
  • Optimisation des performances et de la stabilité à plusieurs endroits : lors de l'enregistrement de votre niveau de course/récupération ou encore lors de la saisit manuelle de l'entraînement que vous avez réalisé. Tout est plus rapide !
  • Interaction améliorée (ordinateur) : ajout de couleurs distinctes au survol et au clic.
  • Optimisation du CSS : j'ai trié le CSS et j'ai également supprimé de vieilles classes que j'avais oublié d'enlever au fil des maj.
  • Amélioration de la robustesse du code de la fonctionnalité qui permet d'exporter son entraînement pour l'envoyer à un ami.
  • Ajustement mineur de l'interface de la page nommé "Nettoyage des données" pour que le bouton "Nettoyer" soit aligné avec le select.

  • Désormais si vous n'avez pas configurer votre profil, vous ne pouvez pas activer le paramètre "Partager mon profil" dans la page "Paramètres discussion".
  • Une icône de partage a été ajoutée à côté du texte "Partager mon profil" pour améliorer l'interface.
  • Une toute nouvelle animation a été ajoutée pour les fênetres flottantes de SPRINTIA Briefing.
