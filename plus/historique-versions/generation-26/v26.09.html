Patch note

Nouvelles fonctionnalités

  • Changement de méthode de calcul pour déterminer la charge d'un entraînement, elle repose désormais sur la méthode sRPE (prouvée scientifiquement). Ce changement permet de corriger des problèmes qu'il y avait auparavant, désormais vos entraînement intenses mais courtes (sprint, VMA) ne sont plus sous estimés, et vos entraînement de récupération ne gonflent plus artificiellement votre charge d'entraînement. Tout votre historique d'entraînement a été mis à jour, donc toutes votre charge d'entraînement a été revue.
  • SPRINTIA adopte le glassmorphism pour la première fois, ce qui permet de se mettre aux goûts du jour car beaucoup d'applications vont vers ce style d'interface à cause/grâce à Apple avec iOS 26 et leurs liquid glass. Ces effets de transparence et de flou donnent de la vie à l'interface lorsque l'utilisateur intéragit avec SPRINTIA.
  • Un nouveau statut a été ajouté pour la chage d'entraînement, il s'agit du statut "Maintien".
  • Vous pouvez enfin rechercher un entraînement dans votre historique d'entraînement.

Améliorations

  • Lorsque qu'une nouvelle mise à jour est publiée, le patch note dans l'onglet "Plus" possède désormais un point bleu pour vous indiquer que de nouvelles fonctionnalités sont disponibles, tant que vous n'aurez pas ouvert le patch note, le point bleu restera visible.
  • Intégration du player youtube directement dans SPRINTIA, ce qui permet de regarder des vidéos youtube sans quitter l'application.
  • La page nommé "Dompté SPRINTIA" a été renommé en "Tutoriels" pour être plus clair et plus compréhensible.
  • Beaucoup d'images des versions ont été supprimées pour alléger la taille de l'application. En plus, désormais j'ai un compte insta exprès pours SPRINTIA donc c'est là bah que je garderais un historique des images des versions précédentes de SPRINTIA.
  • Désormais les icônes des shorcuts sont bleues, ce qui permet de renforcer l'identité de SPRINTIA.
  • Le versionning des mises à jour a été revu pour améliorer la compréhension aux yeux de tous. Désormais, le numéro de version est sous le format vYY.MM, par exemple v26.09 signifie que c'est la version de septembre 2026, et v26.10 sera la version d'octobre 2026.

Correction des bugs et optimisations

  • Séléction de texte lors d'appuie long désactivé.
  • Correction d'une erreur de design pour les balises "select".
  • Correction d'un léger bug lors d'un appui sur un bouton associé à SPRINTIA Briefing.
  • Correction d'un bug lors de l'import d'un fichier TCX, le sport était parfois mal détecté car certains fichiers TCX ne respecte pas les conventions de nom de sport, donc désormais j'ai augmenté les chances de détection du sport.
  • Les variables CSS ont été totalement retravaillées pour améliorer mes interfaces car auparavant, je devais mettre d'autres valeurs pour certains éléments spécifiques, ce qui rendait le code un peu plus complexe.
  • Certains titres de fonctionnalités que je considérais comme trop long ont été raccourcis pour être plus percutant et plus clair.
  • Correction d'un bug : dans le détail de l'entraînement, le nom du coach que vous avez configuré ne s'affichait pas, il restait sur la valeur de base : "JRM Coach".
  • Le header a été optimisé pour améliorer l'expérience sur tablette, la tab-bar a également été un peu retravaillée.
  • Plusieurs éléments d'interface ont été légèrement revus pour améliorer le design et la cohérence dans SPRINTIA.
